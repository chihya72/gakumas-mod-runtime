# Gakumas In-Game Mod Manager

学园偶像大师 DMM 版的游戏内 AssetBundle Mod 管理器。

当前仓库处于规划阶段，尚未包含可运行代码。第一版目标是：在游戏内查看服装与发型 Mod、显示它们对应的游戏内目标图标与名称，并修改下次启动时的启用状态。

完整规划见 [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md)。
